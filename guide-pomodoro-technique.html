How to Use the Pomodoro Technique With an Online Timer

How the technique works, how to run it with a countdown timer or interval timer, and ways to adapt it.

The Pomodoro technique is a simple way to organise work into short, focused blocks separated by breaks. It was developed by Francesco Cirillo in the late 1980s, and it is named after the tomato-shaped kitchen timer he used as a student. The idea is that a time limit makes starting easier, and regular breaks protect your attention. All you need is a timer.

The basic method

  1. Pick one task. Write it down so you know exactly what you are working on.
  2. Set a timer for 25 minutes. This block is one "pomodoro".
  3. Work on the task only. If something else comes to mind, jot it on a list and return to the task.
  4. When the timer ends, take a 5-minute break. Stand up, stretch, drink some water. Avoid anything that pulls you into another task.
  5. After four pomodoros, take a longer break of 15 to 30 minutes.

Set it up with the countdown timer

The simplest way to run Pomodoro is with the countdown timer:

  1. Open the countdown timer and set 25 minutes. Save the timer under the name "Focus" so you can load it with one tap in future.
  2. Create a second saved timer for 5 minutes named "Break", and a third for 15 minutes named "Long break".
  3. Press Start on "Focus", work until the alert sounds, then switch to "Break".

Saved timers are stored in your browser, so they will be there the next time you visit.

Or build the whole cycle in the interval timer

If you would rather not switch timers by hand, the Pomodoro timer runs the whole cycle for you, and the interval timer can chain the cycle into one routine. Add steps named "Focus 1" at 1500 seconds, "Break" at 300 seconds, and repeat to make four focus blocks, with a "Long break" at 900 seconds at the end. Save it as "Pomodoro" and a sound plays at each change. The interval timer runs the list once, so add the steps for the number of blocks you want to do.

Adapting the method

25 and 5 is a starting point, not a rule. Some people find it too short for deep work and too long for tasks they dislike. Common variations include:

  • 50 / 10: longer blocks for writing, coding or study that needs sustained concentration.
  • 15 / 3: shorter blocks to get started on a task you have been avoiding.
  • 90 / 20: a long block for creative or technical work, with a proper break.

Try a pattern for a week and adjust. If you are constantly interrupted before the timer ends, the block is probably too long for your environment.

Making the breaks count

  • Move away from the screen. A short walk, stretching or looking out of a window is better than switching to your phone.
  • Drink water and, if you can, get some daylight.
  • Do not start another task in the break. The point is to rest your attention.

Handling interruptions

If someone interrupts you, ask whether it can wait until your break. If it cannot, pause or reset the timer, deal with it, and start a fresh block. A pomodoro that was interrupted is not a failure, but it should not be counted as a completed block either. Keeping a simple tally of completed blocks per day, for example with the tally counter, helps you see how much focused time you really do.

Common questions

Pomodoro suits tasks that can be done in short bursts, such as study, writing, email, tidying, and coding. It is less suited to work that cannot be paused, like some creative flows. If you are deep in something, you can let the timer go off and continue, then take your break when you reach a natural stopping point.

Frequently Asked Questions

How long is a Pomodoro?

The classic Pomodoro is 25 minutes of focused work followed by a 5-minute break. After four pomodoros, take a longer break of 15 to 30 minutes.

Can I change the Pomodoro times?

Yes. 25 and 5 is a starting point. Many people use 50 and 10 for deep work or 15 and 3 for tasks they are avoiding.

Can StopwatchPro run the whole cycle automatically?

The interval timer can chain focus and break steps into one routine that runs from the first step to the last. Add steps for as many blocks as you want, then save the routine.

Does the timer still work if the tab is in the background?

Browsers can slow background tabs to save battery, which can make timing drift. For important sessions, keep the tab visible and your device awake.
